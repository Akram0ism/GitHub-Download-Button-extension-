GitHub Download Button

Privacy Policy

Last updated: August 11, 2026

Overview

GitHub Download Button is a browser extension that adds convenient download controls to GitHub repository pages. The extension is designed to let users download an entire repository, individual folders, or individual files.

We do not collect, store, sell, or share personal information. We do not operate an analytics or tracking service for this extension.

Data the extension accesses

To provide its download functionality, the extension may access information that is already available on the GitHub page you are viewing, such as:

  • the repository owner and repository name;
  • the current branch or file path;
  • repository file and folder information required to perform a download.

This information is processed only as needed to provide the download feature and is not sent to or stored on servers operated by the developer.

GitHub requests

The extension may make requests directly from your browser to GitHub services, including github.com, api.github.com, and raw.githubusercontent.com. These requests are used only to retrieve repository, folder, or file content requested by the user.

GitHub may process these requests according to GitHub's own terms and privacy policy. The developer of GitHub Download Button does not receive the contents of those requests.

Personal data and browsing activity

The extension does not collect names, email addresses, authentication credentials, payment information, precise location, browsing history, or other personal information.

The extension runs on GitHub repository pages solely to provide its visible download features. Page access is not used for advertising, profiling, tracking, or monetization of browsing activity.

Cookies, analytics, and advertising

  • No developer-operated cookies are used.
  • No analytics or telemetry is collected by the extension.
  • No advertising SDKs are included.
  • User data is not sold or transferred to third parties for advertising purposes.

Data retention

Because the extension does not collect or store user data on developer-operated servers, there is no developer-side user data retention. Files downloaded by the user remain on the user's device and are controlled by the user and the browser.

Permissions

Host access is limited to GitHub-related domains required for the extension's single purpose: adding download controls and retrieving the GitHub content that the user chooses to download.

Changes to this policy

If the extension's data practices change, this Privacy Policy will be updated to reflect those changes. Material changes to data handling will also be disclosed where required.
